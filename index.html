Referencia de Especificación JSON Schema

  • "type": Tipo de dato ("string", "integer", "number", "boolean", "object", "array").
  • "required": Lista explícita de campos obligatorios en un objeto.
  • "items" / "minItems": Define el esquema de elementos dentro de una lista y su cantidad mínima.
  • "minimum" / "maximum" / "enum" / "pattern": Restricciones cuantitativas, valores permitidos o expresiones regulares.

Referencia de Especificación XML Schema (XSD)

  • <xs:complexType> / <xs:sequence>: Contenedores para elementos con sub-elementos ordenados.
  • <xs:attribute name="..." type="..." use="required">: Declaración de atributos de elementos.
  • minOccurs / maxOccurs: Ocurrencias permitidas (ej. maxOccurs="unbounded").
  • <xs:restriction base="...">: Restricción mediante <xs:pattern> o <xs:enumeration>.
