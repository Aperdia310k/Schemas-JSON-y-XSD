Guía Rápida: Palabras clave en JSON Schema

  • "type": Define el tipo. Valores: "string", "integer", "number", "boolean", "object", "array".
  • "required": Lista de campos obligatorios. Ejemplo: ["nombre", "edad"].
  • "minimum" / "maximum": Restricción numérica. Ejemplo: "minimum": 18.
  • "$schema": Vincula el archivo de esquema en el documento JSON.

Guía Rápida: Palabras clave en XML Schema (XSD)

  • <xs:element name="..." type="...">: Declara un elemento. Tipos: xs:string, xs:integer, xs:decimal.
  • <xs:sequence>: Especifica que los elementos hijos deben ir en orden estricto.
  • maxOccurs="unbounded": Permite que un elemento se repita sin límite.
  • xsi:noNamespaceSchemaLocation: Atributo para asociar el fichero .xsd en la raíz del XML.
